# 🛡️ Palo Alto Networks Next-Generation Firewall (NGFW) & Threat Prevention Lab

Comprehensive deployment of **Palo Alto PAN-OS** in virtualized enterprise environments (EVE-NG), implementing perimeter defense, stateful policy enforcement, WildFire malware analysis, and Site-to-Site IPsec VPN.

## 📌 Roadmap Alignment: Networkers Home Cyber & Cloud Security
- **Specialized Security:** Next-Gen Firewall (Palo Alto PAN-OS)
- **Security Policies & Objects:** Address groups, service definitions, custom application IDs
- **NAT:** Source NAT (PAT / Overload) and Static Inbound Destination NAT (DNAT)
- **Threat Prevention:** Anti-Virus, Anti-Spyware with DNS Sinkholing, and Vulnerability Exploit Protection
- **WildFire & URL Filtering:** Cloud sandboxing for zero-day threats and categorized web URL filtering
- **VPN:** IKEv2 / IPsec Site-to-Site VPN tunnel with AES-256-GCM encryption

## 📁 Repository Contents
- `configs/security_policies.txt`: Stateful zone-based access control rules & NAT configurations.
- `configs/threat_prevention_wildfire.txt`: Anti-Virus, Anti-Spyware, Vulnerability Protection & WildFire profiles.
- `configs/site_to_site_ipsec_vpn.txt`: IKE Phase 1 & Phase 2 IPsec tunnel configuration.
